# 小说改编全书分析方法

## 一、来源与覆盖

记录作品版本、卷章或场景分隔、总单元数、可读范围和授权边界。生成稳定边界表：

`编号 | 标题 | 起止位置 | 状态`

逐单元处理后检查：

```text
成功单元集合 == 来源边界集合
```

读取缺口进入来源范围与风险。已有拆文产物按相同边界核对覆盖，再复用其中的剧情、人物、设定与
节奏资料。

## 二、逐单元记录

每个单元使用紧凑卡片：

| 字段 | 记录内容 |
|---|---|
| 剧情变化 | 本单元开始状态、主要事件、转折和结束状态 |
| 人物行动 | 谁主动做了什么，想得到什么，付出什么 |
| 知识变化 | 谁知道、误解、隐瞒或确认了什么 |
| 关系变化 | 信任、地位、利益、称呼、承诺和冲突怎样变化 |
| 选择空间 | 人物曾有哪些真实可行的做法，各自影响什么 |
| 规则与代价 | 世界、能力、社会和资源规则如何运作 |
| 空间与物件 | 地点、通路、门槛、物件归属与去向 |
| 节奏与情绪 | 压力、缓和、悬念、揭示与回收 |
| 视听锚点 | 人物、场景、动作、材质和声音 |
| 证据与边界 | 原文位置、事实类型与冲突 |

无新增的字段写“无新增”，保留单元覆盖记录。

## 三、人物引擎

为核心人物建立跨阶段档案：

- 当前目标与长期欲望；
- 害怕失去的东西；
- 掌握、误解和隐瞒的信息；
- 对其他人物的判断；
- 可以主动采取的行动；
- 关系与身份变化；
- 说话方式、称呼、礼仪和行动习惯；
- 结局及早期伏笔回收。

人物行动按阶段排序，形成“目标 → 行动 → 结果 → 新目标”的链。后续概念可以据此判断玩家扮演
主角、原创角色、观察者、势力或其他身份时能够介入什么。

## 四、剧情与关系聚合

按三层压缩：

1. **单元层**：保留局部事件、人物行动与事实变化；
2. **阶段层**：按剧情目标、地点或关系转折聚合，记录开始、升级、转折、结果；
3. **全书层**：比较各阶段，提炼核心冲突、人物弧、关系网络、世界因果和主题回收。

关系网络使用事件支撑。每条核心关系记录初始状态、关键交换、公开变化、私下变化、破裂或修复、
最终状态和证据。

## 五、知识、秘密与证词

为影响剧情判断的事实建立知识表：

| 事实 | 真相 | 知情者 | 误解者 | 隐瞒者或说谎者 | 证据物件 | 揭示时刻 |
|---|---|---|---|---|---|---|

区分叙述事实、角色说法、角色误解和版本冲突。人物的后续言行只引用当时已经掌握的信息。

## 六、世界、空间与物件

世界规则记录条件、代价、例外、反制和可观察后果。社会规则记录身份、名分、礼制、官阶、契约和
惩罚。能力规则记录输入、效果、限制和使用者。

空间记录入口、出口、通路、门槛、危险、地标和人物活动。关键物件记录来源、持有者、用途、转移、
损坏和最终去向。

## 七、改编机会

从原作事实提出玩家介入问题：

| 原作材料 | 改编问题 |
|---|---|
| 人物目标冲突 | 玩家能支持、阻止、误导或调停谁？ |
| 秘密与证词 | 玩家如何获得、解释、隐瞒或公开信息？ |
| 关系变化 | 哪些行动会被人物记住并在后文回响？ |
| 世界规则 | 玩家能用哪些动作改变处境？ |
| 空间与物件 | 玩家能到哪里、拿到什么、把它交给谁？ |
| 主题选择 | 哪个节点最能让玩家表明立场并承担结果？ |

这些问题进入概念阶段比较叙事主导、混合型和系统主导方向。

## 八、事实回查

关键转折、人物身份、关系、数值、等级、距离、口令、能力边界、死亡和结局回到原文位置核对。
冲突事实分别记录位置与说话者。原文留白进入 `open`，版本冲突或叙述冲突进入 `conflicted`。

聚合结论选择建立、典型运作、重要反例和最终回收位置作为证据。术语表保持人名、称谓、地点、
物件和文化概念一致。

## 九、交付压缩

SOURCE_BIBLE 保存会影响概念选择与后续场景、人物、规则设计的事实。过程卡用于覆盖、恢复和回查；
全书结论使用剧情脊柱、人物表、关系表、知识表、规则表和改编边界表表达。
