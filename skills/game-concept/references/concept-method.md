# 概念选择方法

## 一、从原作价值开始

先回答三个问题：

1. 读者记住这部小说，主要因为哪些人物、关系、情节、世界规则或情绪？
2. 玩家进入其中后，最值得亲手影响什么？
3. 首个原型用哪一段冲突就能让这种影响被看见？

答案形成几种参与假设。人物关系、秘密、证词与伦理抉择可以由场景、观察、表达和关键决定承载；
空间行动、资源竞争、能力规则和反复对抗可以由动作、规则与反馈承载。概念比较决定各层职责。

## 二、玩家参与故事的方式

场景与人物可以组合四种参与方式：

- **观察**：从环境、物件、证词和人物反应中获得信息；
- **判断**：决定相信谁、如何解释事实、愿意承担什么代价；
- **表达**：通过对白、沉默、承诺、隐瞒或公开立场塑造关系；
- **行动**：拜访、调查、交付、保护、揭露或离开，让选择进入世界。

对话和阅读承担信息、表演与情绪。关键节点让玩家把理解转成选择，后续场景再用人物行动、对白
变化、可达信息和结局回收这次选择。

隐藏因果按“写入事实 → 后续读取 → 玩家感知”设计。事实可以是玩家说过的话、知道的秘密、
留下的物件、公开站队或人物对玩家的具体记忆。玩家通过场景变化理解因果，界面只展示当前处境
真正需要的信息。

## 三、参考作品怎么选

参考作品围绕设计问题选择：

| 设计问题 | 研究重点 |
|---|---|
| 人物表现 | 人物如何主动发起行动、保留秘密并改变关系 |
| 关键选择 | 选择如何形成价值冲突，并在后续场景中回响 |
| 信息控制 | 玩家、主角和各人物分别知道什么，何时得知 |
| 场景结构 | 连续场景如何推进压力、转场和人物目标 |
| 系统动作 | 哪些动作能持续产生判断、反馈和熟练度 |
| 剧情与系统连接 | 系统结果怎样改变剧情，剧情事实怎样改变系统选择 |
| 文化表达 | 原作文化怎样表达身份、关系、禁忌和情绪 |

用商店页、开发者说明、演讲、可靠评测或玩法资料核实事实。记录来源与日期，再写当前项目从中
采用的原则。

## 四、关键选择的质量

一个关键选择写清五件事：

1. 玩家此刻知道什么；
2. 各选项代表什么立场或行动；
3. 当下发生什么；
4. 哪个隐藏事实被写入；
5. 后续哪个场景、人物或结局会读取它。

好的选项是人物在压力下采取的策略，让玩家在价值、关系、信息和未来机会之间面对不可兼得的
取舍。选项文本保持角色语境，不使用作者的道德标签，也不预告后果；提交后的即时反应与后续场景
的延迟回响共同表达代价。汇流点可以共享制作量，同时保留人物记忆、信息差和关键场景的区别。

## 五、系统与剧情的连接

原作规则可以进入玩家反复使用的动作、空间和反馈。概念承诺剧情与系统相互影响时，为相关状态
指定具体消费点。

数值只在确实承载资源、风险、距离、时间或能力时出现。人物承诺、背叛、认同和秘密优先记录为
具体事实，使后续对白和行动能够准确回读。

## 六、概念比较

比较时优先看：

- 玩家是否能进入原作最有价值的冲突；
- 主要人物是否拥有自己的目标与行动；
- 关键选择或核心动作是否产生后续区别；
- 场景、规则和反馈是否形成连贯体验；
- 10–30 分钟原型是否能走到一个完整结果；
- 当前方向是否值得扩成更长内容。

最终推荐用一段话说清：玩家扮演谁，连续做什么，哪些人物或规则会回应，以及首个原型准备验证
哪一个最危险的判断。
