# 对白与互动选择设计方法

对白承担主要体验时，用本方法把人物目标、信息权限和玩家选择写成可实现的场景。它不规定台词
长度、选项数量或固定节拍；这些由原作、人物、平台与当前场景决定。

## 一、先回答场景五问

写逐字台词前回答：

1. 删掉本场会损失哪项选择、证据、关系变化或不可逆行动；
2. 谁是焦点人物，他此刻想让谁做什么；
3. 谁或什么反制，掌握什么筹码；
4. 本场让什么变得可见、已知、决定或不可逆；
5. 哪项退出状态发动下一场，而不只是宣布“谈话结束”。

相邻场景用人物行动、未付代价、证据去向或关系变化相连。只有时间相邻而没有因果连接的场景，
不算连续剧情。

## 二、建立对白议程

为会改变局面的参与者各写一张对白议程：

| 项目 | 要回答的问题 |
|---|---|
| 当前要求 | 此刻想让对方做、交出、承认、停止或相信什么 |
| 害怕暴露 | 最怕哪项事实、欲望、软弱或关系被看见 |
| 筹码 | 能提供、扣留、证明、破坏或公开什么 |
| 初始策略 | 先试探、交换、划界、推责、威胁、保护还是转移 |
| 策略受阻 | 对方怎样拒绝；随后换成什么策略，而不是把原话说得更响 |
| 底线 | 哪件事通常不会做；什么压力可能迫使其越线 |

先写行动链，再写台词：

`A 以策略和筹码行动 → B 回应或拒绝 → 权力、信息、关系、物件或站位变化 → A 换招/退出`

每轮应接住上一轮动作，并改变下一轮能做什么。可以维持僵局，但僵局必须增加代价、暴露策略或
改变理解。纯粹重复立场的往返应压缩。

## 三、让台词成为行动

给关键台词标一个主要动作，例如：试探、交换、划界、推责、威胁、保护、转移、求证、拒绝、
承诺、诱导或撤回。不要把已经由物件、站位或对方反应表达的意义再解释一遍。

动作段只在它会完成至少一件事时出现：

- 操作筹码或证据；
- 改变距离、出口、视线或空间权力；
- 暴露言行不一；
- 给对方一个必须回应的新事实；
- 记录后续必须继承的连续性变化。

“看了看”“笑了笑”“沉默片刻”若不改变策略，只是表演填充。沉默可以保留，但要说明人物用
沉默拒绝、试探、拖延、保护或迫使谁先行动。

## 四、建立人物声音卡

人物声音不只是一组口头禅。为核心人物写人物声音卡：

- 他认定什么才算证据，注意流程、体面、感受还是具体物件；
- 面对亲友、上级、陌生人和需要保护的人分别采用什么关系策略；
- 常用怎样的称呼、句式、停顿对象与回避方式；
- 压力升高时会变得更精确、更含糊、更礼貌、更短促，还是改用行动；
- 哪条底线被触碰时，声口会发生可追溯的变化。

使用“交换说话者测试”：交换两人的名字后，若关键台词仍完整成立，检查是否缺少不同的目标、
证据观、关系策略或知识边界。不要只靠生僻词和口癖制造差异。

## 五、管理信息权限与证据边界

同一事实同时维护三层状态：

1. **世界事实**：作品内部实际发生了什么；
2. **人物相信**：每名人物知道、误信、怀疑或隐瞒什么；
3. **玩家知道**：玩家当前看见、听见并能合理推断什么。

人物只能使用当前已获得的信息。揭示应改变某人可以采取的行动，而不只是补充百科答案。

每项关键证据再拆成：

- **可见载体**：证词、文件、伤痕、钥匙、位置、声音或可复核行为；
- **直接支持**：该载体足以确认的最小结论；
- **未决推断**：仍可能成立、但载体尚未证明的解释、动机或责任。

角色可以误判，但设计文件必须保留这三层区别。新揭示可以改变旧证据的意义，不能凭空改写已经
发生的事实。

## 六、把互动选择写成角色行动

选项表达主角此刻采用的说法、姿态或行动，不使用“善良 / 邪恶”“信任 / 怀疑”等作者标签。
关键选择应满足：

- 玩家在选择前拥有足以判断处境的信息，但选项不预告后果；
- 两条路在价值、关系、信息、未来机会或自我保护上不可兼得；
- 提交后先出现人物或现场的即时反应；
- 后续场景通过称呼、证据去向、可用行动、人物站位或结果产生延迟回响；
- 汇流时保留人物记忆，不把未选行动当作已发生；
- 结果呈现当前代价和仍在运动的压力，不逐项解释隐藏状态。

每个隐藏事实记录 `写入 → 第一次读取 → 延迟读取 → 玩家感知`。隐藏状态服务剧情因果，不用公开
数值替玩家解释关系。

## 七、避免模板化对白

逐场并排检查，而不只逐句润色：

- **过度解释**：动作或证据已表达后，台词又翻译心理、主题或道德意义；
- **过度收口**：场景和结果都用总结句封死余波，下一场只能重新制造压力；
- **过度工整**：每轮都是同样长度、同样句式、同样的问答与微动作；
- **信息密度均匀**：每一拍都同样“有信息”，导致真正的证据与决定没有重量；
- **策略重复**：人物只会质问—否认—提高音量，筹码与行动条件从不变化；
- **选择模板重复**：连续场景都按“说明 → 二选一 → 一句回应”运行。

修订时保留原作承诺与已批准选择，优先删解释、合并重复轮次、让反对方使用筹码、改变信息密度，
并让物件或空间动作承担一部分意义。不要用固定字数、对白比例或选择数量冒充质量。

## 八、交付与审查

在 `GAME_DESIGN.md` 交付：场景五问、核心人物议程、人物声音卡、信息权限表、证据边界、选择因果
和结果余波。交付前：

1. 交换说话者，检查人物是否仍可辨认；
2. 反向走读分支，确认未选事实没有串入；
3. 标出每场至少一项可见变化与退出压力；
4. 删除重复解释，但保留玩家作选择所需的证据；
5. 把自然度、人物魅力、沉浸和选择重量留给独立文案审查与目标玩家试玩，不写成自动化结论。
