# Visual Targets · Project Plateau

`targetFinish: playable-prototype`
Representative scene: **glade family discovery under approaching aerial pressure**

This package is an original composition guide for the existing runtime. It is
not a claim that the implementation has passed visual review. The diagrams use
only authored vector shapes and the baseline/after captures are generated by
the local build. Modern adaptation imagery and assets are excluded.

## Frame rubric

Every captured view is judged independently; scores do not average away a
major defect.

| Dimension | Required evidence | Major defect |
|---|---|---|
| Focus | One primary subject is identifiable before UI text. | HUD or an incidental bright patch becomes the first read. |
| Silhouette / anatomy | Adult/young proportions, grounded limbs, lifted tail and thumb/hand accents; pterodactyl has long wing digit, membrane plane, narrow head and compact torso. | Tail-dragging/kangaroo stance, fused legs, bird/bat outline, or toy block assembly dominates. |
| Spatial depth | Foreground occluder, playable middle distance and distant plateau/sky have distinct value and scale bands. | World collapses into one flat row of repeated props. |
| Material / line | Matte slate hide, warmer underside, fractured basalt, damp soil/brook and translucent membrane edge separate by response, not gloss alone. | One standard material makes terrain, foliage and creatures interchangeable. |
| Light / colour | Warm glade lane isolates evidence while cool canopy/fog retains route and threat readability in non-colour modes. | Full-screen tint, bloom or darkness hides the decision. |
| HUD | One contextual instruction; physical plate/tool feedback remains subordinate to the world. | Large panel or waypoint supplies route/threat information absent from the scene. |
| Motion / feedback | Heavy young arcs and branch pull differ; orbit, watch, bank, dive and cover pull-up differ in cadence and pose. | Hovering threat, uniform bobbing, clipping, or feedback that exists only in text. |
| Artefacts | No clipping through the subject corridor, broken shadows, blank frames or unstable camera horizon. | Any blocker obscuring input or evidence state. |
