# Project Plateau visual-upgrade evidence

This directory retains only the compact written audit for the visual-fidelity change.

- [`WEB_OCEAN_GAP_AUDIT.md`](WEB_OCEAN_GAP_AUDIT.md) records the evidence-versus-inference
  comparison against the pinned Web Ocean reference.
- [`../current-run/`](../current-run/) is the authoritative final browser capture. Its report and
  32 fixed review frames cover launch, rendering, input, the core loop, the designed outcome,
  restart, and the final physical/visual inspection views.

Intermediate before/after captures, rejected experiments, per-pass reports, and duplicate
comparison frames are reproducible working artifacts and are intentionally not versioned. This
keeps the repository aligned with the narrow-evidence policy in `CONTRIBUTING.md` while preserving
the final run needed to review every current claim.
