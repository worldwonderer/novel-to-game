# Canopy leaf hierarchy v3 pass

## 目标

在不改变 128 个树木锚点、树干碰撞、森林群落布局、日光或曝光的前提下，使原始冠层资产从“枝架上稀疏大叶片”推进为可读的三维枝端叶簇。

## 物理约束

- 每片叶的根点与一个封闭末端枝条锚点重合；没有漂浮冠层团块。
- 根、树干和枝条保持封闭承重链；树干垂直沉降，碰撞仍只覆盖可见树干。
- 叶片是非金属、零发光的薄介质；颜色和深度阴影使用相同风位移。
- 不改太阳、环境光、曝光、雾或 bloom 来掩盖叶片几何问题。

## 被否决的 v2

`rejected-flat-leaf-fans/` 增加了叶片数量，但同一枝端主要沿水平扇面展开，近景读成重复薄片/托盘。该结果没有通过三维朝向与连续受光变化门槛。

## 接受的 v3

- 将单叶长度由 `0.55..0.68 m` 收敛到 `0.40..0.49 m`，Araucaria 由 `0.38 m` 收敛到 `0.28 m`。
- 每个枝端使用黄金角叶序绕枝轴分布，局部侧向、法向与重力上方向共同决定叶片姿态，不再使用一个水平扇面。
- 四个家族共有 `3,600` 片枝端附着叶，分别为 `810/702/900/1,188`；四个资产共 `16,380` 三角形。
- 128 个主树实例渲染 `532,740` 树木三角形，八个 draw calls；浏览器证据记录 `59.9 FPS` 中位数、`39.2 FPS` 1% low、`25.6 ms` 最差帧。
- `3,540/3,540` 根部支撑点仍埋入同一渲染高度场，所有实例通过 `10 m` 冠幅和 `9.9 m` 成熟高度包络。

`before/` 与 `after/` 固定保存 brook、glade 和 canopy-detail 镜头；自动 PASS 只证明运行、物理契约和机械画面健康，不证明已经达到 Web Ocean 的主观画质。
