# Rejected visual attempt: dotted carpet

This capture is intentionally retained as a failed visual iteration.

The automated run passed, but the terrain shader applied roughly 1–1.4 cm of
fine relief across broad surfaces. Combined with a permissive mineral gate, the
stone and pore masks repeated as evenly distributed dots, making the forest
floor read like a patterned carpet rather than physically accumulated soil.

The attempt was rejected. The follow-up narrows inclusions to geological and
habitat sources, raises mask thresholds, and reduces universal fine relief to a
subtle millimetre-scale response.
