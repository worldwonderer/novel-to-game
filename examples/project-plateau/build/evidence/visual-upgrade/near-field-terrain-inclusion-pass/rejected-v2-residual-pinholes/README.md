# Rejected visual attempt: residual pinhole field

The second automated run passed mechanically, but the close forest-floor frame
still exposed a dense, evenly spaced field of bright/dark pinholes. Lowering the
relief amplitude did not repair the distribution: the candidate mask still
placed one cellular feature in almost every texture cell.

The attempt was rejected. The follow-up removes universal high-frequency height,
uses deterministic sparse occupancy with variable feature radius, and limits
fine normal relief to source-gated mineral inclusions.
