# Rejected: sparse pollarded crown

The curved trunk, buried buttress roots and finer supported twigs passed mechanics and performance,
but the fixed hero view failed visual acceptance. The 11.8 m trunk terminated as a visible flat-cut
pole above a sparse outer crown, and leaf-bearing nodes existed only on terminal twigs. This read as
a recently pollarded prop rather than the approved mature Fort landmark. The version is retained as
evidence and is not the accepted asset.
