# Rejected sparse / green-rhizome fern trial

The first physically supported GLB passed topology, grounding and wind-coupling checks, but the fixed
inspection camera exposed three visual failures:

- eight or fewer narrow leaflet pairs left the rachises reading as wire or caterpillar-like stems;
- the exposed rhizome was too round and green, so the root crown read as a planted pot rather than a
  low buried organic support;
- the leaflet area was too small relative to the rachis diameter, making the intended heavy fern
  family visually lighter than the procedural foliage it replaced.

The accepted asset keeps the same support plane and load path. It lowers and darkens the rhizome,
reduces rachis radius, raises the families to 10–13 leaflet pairs per frond, and uses broader cambered
leaflet geometry. No exposure, emission, bloom or support-threshold change was used to hide the defect.
