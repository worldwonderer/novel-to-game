# Rejected: symmetric bench and radial track carrier

This candidate passed the input path and performance gates, but was rejected visually and
physically:

- deposition was based mainly on distance from the channel, so both banks received nearly the same
  treatment instead of distinguishing point-bar accretion from cut-bank erosion;
- the tridactyl impression's entire elliptical carrier remained opaque until its outer radial fade,
  producing a pale circular halo unrelated to pressure or displaced mud;
- the glade and brook fixed frames remained too close to the prior broad brown-floor result.

No exposure, fog, sun, emission or bloom value was changed to hide those failures.
